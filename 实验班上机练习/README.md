## A:Familiar？
我们能够通过给出的 $c_1, c_2, \ldots, c_n$ 来还原出第几次插入的元素去了哪个位置。

因为每次插入操作都会将新插入的元素放在堆的最后一个位置，而其父节点的位置也是确定的。

而最终堆是已知的，因此我们可以还原出一个候选插入序列，按照每次插入的对应交换次数使得最终得到最终堆。

最终我们检验候选插入序列插入的每个数是否能合法得到对应的交换次数即可。
## B:环形匹配
对于 $S$，我们可以通过对索引取模来实现首尾连接的待匹配字符串。

然后用 $T$ 在虚拟串上做 KMP 匹配即可。

细节上，我们先求出 $T$ 的前缀函数，利用 KMP 算法的在线性，我们只需要储存 $T$ 的前缀函数即可，而不需要生成出虚拟串来进行拼接做传统 KMP 匹配。
## C:中转网络
我们要选取基础的路径权重再减去最大节点值再增加最小节点值，这其实直接就是 $min(base-a_x+a_y)$

对于每个节点，我们可以将是否已使用增加节点权重和已减去节点权重记录为四种状态，故而全图应有 $4(n+k)$ 个状态。

对于中转站，我们可以构造一个路上花费为 0 的虚拟节点。

记录完所有的边之后，我们就可以使用 Dijkstra 算法来求出最短路径了。
