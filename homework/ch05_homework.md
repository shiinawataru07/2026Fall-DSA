### 2

证明：一棵二叉树的所有终端结点（叶节点），在前序序列、中序序列、后序序列中都按相同的相对位置出现。

对树的节点数量进行归纳：  
对于仅有根节点的树来说是成立的。  
对于一般的树来说，根节点不是叶节点，假设对于节点数量小于 $n$ 的树均有此结论成立，考虑节点数量为 $n$ 的树，设其根节点为 $r$，左子树为 $T_L$，右子树为 $T_R$。  
假设两个叶节点均落于左子树或者右子树中，则根据归纳假设，叶节点在前序、中序、后序中的相对位置均相同。  
假设两个叶节点分别落于左子树和右子树中，前序/中序/后序序列中仍然不改变左子树与右子树的相对位置，叶节点在前序、中序、后序中的相对位置均相同。

### 3

哈夫曼树是一种基于贪心算法构建的树结构，并且带权路径长度最小，在数据编码（如文件压缩）得到了广泛应用。请基于哈夫曼树的性质，解决以下问题：

1. 如果一棵哈夫曼树中有 199 个结点，请求解该哈夫曼树中叶子结点个数。
2. 假设用于通信的电文仅由 8 个字母组成，依次记为 1 至 8 号字母，其出现频率分别为 `0.07, 0.19, 0.02, 0.06, 0.32, 0.03, 0.21, 0.10`。试为这 8 个字母设计哈夫曼编码。
3. 使用 0~7 的二进制表示是另一种编码方案。对于上述实例，比较两种编码方案的优缺点。

答案  
1. 叶子节点有 100 个。
2. 构建哈夫曼树
```
                                1.00
                                /  \
                            0.6      0.4
                          /    \      /  \
                        0.28  0.32  0.19  0.21
                      /    \     [5]  [2]   [7]
                    0.11   0.17
                  /   \    /   \
                0.05 0.06 0.07 0.10
               /   \   [4] [1]  [8]
            0.02   0.03
            [3]    [6]   
```
于是 [1]: 0010，[2]: 10，[3]: 00000，[4]: 0001，[5]: 01，[6]: 00001，[7]: 11，[8]: 0011

3. 哈夫曼编码的优点是能够根据字符出现的频率来设计最优的编码方案，使得加权平均码长最短，从而实现数据压缩。缺点在于，哈夫曼编码需要构建哈夫曼树，编码和解码的过程相对复杂。而使用固定长度的二进制表示（如 0~7 的二进制表示）则简单易用，但无法根据字符频率进行优化，可能导致平均码长较长，从而增加数据传输的开销。

### 4

使用堆的性质解决以下问题：

1. 已知待排序的序列为 `(503, 87, 512, 61, 908, 170, 897, 275, 653, 462)`，根据以上序列建立一个堆（画出第一步和最后堆的结果图），希望先输出最小值。
2. 设有一个最小堆，即堆中任意结点的关键码均 **小于等于** 它的左子结点和右子结点的关键码。其具有最大值的元素可能在什么地方？
3. 对 `n` 个元素采用自底向上的方法初始建最小堆（从最后一个非叶结点开始依次向下调整）。以关键码比较为基本操作，证明最坏情况下比较次数 `T(n) < 2n`，从而说明建堆时间为 `O(n)`。请给出推导过程。

答案：  
1. 从后往前遍历，依次调整每个非叶结点，使其满足最小堆的性质。  
最初堆的结果图：
```
          503
         /  \
       87    512
      / \    / \
    61  908 170 897
   / \   /
 275 653 462
```
最终堆的结果图：
```
          61
         /  \
       87    170
      / \    / \
    275  462 512 897
   / \   /
 503 653 908
```
2. 可能在任何的叶子节点中，或者在某个出现在叶子节点上的最大值的祖先节点中（那条路径上均为最大值且相等，因为最小堆只保证小于等于）
3. 每一层至多有 $2^i$ 个节点，因此
$$ cost \leq \sum_{i=0}^{h}2^i(h-i)=\sum_{j=0}^h2^{h-j}j=2^h\sum_{j=0}^h\frac{j}{2^j}\lt 2^h\times 2 \leq 2n $$

### 5

给定 `n >= 1` 个非负权值 $w_1, w_2, \ldots, w_n$ 和整数 `k >= 2`，说明怎样构造具有最小加权路径长度的 `k` 叉树。试对于权值集合 $\{1, 2, 3, 4, 5\}$ 构造最优的 `3` 叉树，并给出其最小加权路径长度。

只需要每次选取其中 `k` 个最小的权值作为一个新的结点的子结点，直到所有的权值都被选取为止。就像构造哈夫曼树一样，只是每次选取 `k` 个最小的权值，而不是两个。
```
        15
       / | \
      6  5  4
    /|\
    1 2 3
```
其最小加权路径长度为 15+6=21 （所有内部节点之和）
